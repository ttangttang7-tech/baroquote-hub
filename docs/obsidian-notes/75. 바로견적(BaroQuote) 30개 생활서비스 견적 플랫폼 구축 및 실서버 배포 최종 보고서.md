## 🌐 5. 공식 사이트맵 표준화: /sitemap.xml

본 프로젝트는 통합 지시서 11항에 따라 **공식 표준 사이트맵 주소를 `/sitemap.xml`로 확정**하고 완벽하게 구현하였다.

```
https://quote.info-myview.co.kr/sitemap.xml
```

### 5-1. 기술적 구현 및 자동화 파이프라인
- `@astrojs/sitemap` 및 전용 사후 빌드 스크립트 `scripts/ensure-sitemap.mjs` 가동
- 빌드 완료 시 `dist/sitemap.xml`에 표준 W3C `<urlset>` 스키마 기반 정규 XML 자동 생성
- 수록 URL 현황 (총 40개):
  - 메인 1개 (`/`)
  - 안내/정책 3개 (`/about`, `/privacy`, `/terms`)
  - 6대 카테고리 6개 (`/category/...`)
  - 30대 견적 도구 30개 (`/estimate/...`)
- `public/robots.txt`:
  ```txt
  User-agent: *
  Allow: /

  Sitemap: https://quote.info-myview.co.kr/sitemap.xml
  ```
- HTML `<head>` 태그 내 `<link rel="sitemap" type="application/xml" href="/sitemap.xml">` 자동 주입
