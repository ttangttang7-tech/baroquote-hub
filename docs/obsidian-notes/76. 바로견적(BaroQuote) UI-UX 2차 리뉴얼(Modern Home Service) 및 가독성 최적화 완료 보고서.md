## 📌 1. 리뉴얼 핵심 배경 및 목표

| 기존 문제점 (Before) | 개선 방향 (After: Modern Home Service) |
| :--- | :--- |
| **과도한 시각적 노이즈** | 화려한 그라디언트, 과다한 이모지 아이콘, 복잡한 다중 테두리를 전면 제거하고 여백과 면 분할 중심의 담백한 UI 구축 |
| **복잡한 뱃지 남발** | 서비스 카드마다 붙어있던 다채색 뱃지들을 정리하고 간결한 단일 카테고리 필(Pill)과 심플한 인증 뱃지로 통일 |
| **가독성 저해 텍스트 줄바꿈** | 모바일 및 반응형 뷰포트에서 한글 단어가 어색하게 잘리던 현상을 `word-break: keep-all` 및 행간·자간 최적화로 완벽 교정 |
| **모바일 터치 타깃 협소** | 견적 질문 선택 칩 및 입력 폼 요소의 높이를 최소 48px 이상 확보하여 엄지손가락 터치 사용성 대폭 향상 |
| **강한 원색 대비 피로감** | 쨍한 블루·보라 대신 따뜻하고 신뢰감을 주는 Deep Teal (`#0D9488`), Soft Emerald (`#059669`), 부드러운 Slate Surface (`#F8FAFC`) 채택 |

## 📐 2. 주요 UI/UX 개선 내역

### 2-1. 공통 디자인 시스템 (`src/styles/global.css`, `DESIGN.md`)
- **색상 체계 정립**:
  - Primary: Deep Teal (`#0D9488`, 호버 `#0F766E`, 라이트 배경 `#F0FDFA`)
  - Accent / Success: Soft Emerald (`#059669`, 라이트 배경 `#ECFDF5`)
  - Background: Soft Slate (`#F8FAFC`), Surface: Pure White (`#FFFFFF`)
  - Typography: Primary Dark Slate (`#0F172A`), Body (`#334155`), Muted (`#64748B`)
- **디자인 토큰 규격화**:
  - 간격(Spacing), 폰트 스케일(Font Scale), 반경(Radius: 6px, 10px, 14px, 18px, 9999px pill) 완전 체계화
  - 부드러운 다단 소프트 섀도우 적용으로 평면적이면서도 세련된 입체감 부여

### 2-2. 메인 홈 (`src/pages/index.astro`)
- **히어로 영역 클린화**:
  - H1 카피 개선: `집수리·청소·이사 비용 / 적정 견적부터 확인하세요` (SEO 키워드 준수 및 2줄 균형 배치)
  - 검색창을 깔끔한 알약형(Pill) 서치바로 정돈하고 추천 키워드 칩을 미니멀하게 배치
- **6대 카테고리 & 30개 도구 그리드**:
  - 카테고리 카드를 48px 소프트 아이콘 박스와 은은한 호버 인터랙션으로 재단장
  - 30개 생활서비스 디렉터리를 탭/그리드 형태로 정돈하여 스크롤 압박 없이 직관적으로 탐색 가능
- **검색 및 필터 기능 보존**: `#toolSearchInput`, `#searchResultsSection` 등 기존 DOM ID 100% 유지

### 2-3. 개별 견적 계산기 페이지 (`src/pages/estimate/[slug].astro`, `EstimateForm`, `EstimateResult`)
- **2열 데스크톱 / 1열 모바일 반응형 레이아웃**:
  - 좌측: 48px+ 터치 타깃 기반 옵션 선택 폼 (단일선택, 다중선택, 숫자 입력)
  - 우측: 부드러운 Teal 배경의 상단 고정(Sticky) 실시간 견적 카드
- **가독성 중심 결과 카드**:
  - 시세 범위 및 산정 세부 내역을 표(Table) 형태 대신 깔끔한 스트립 카드로 표현
  - 견적 복사 및 공유 버튼을 직관적인 텍스트 및 마이크로 아이콘으로 재구성
- **체크리스트 & FAQ**: 차분한 아코디언 스타일로 정돈하여 정보 탐색 편의성 제고
